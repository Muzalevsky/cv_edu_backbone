# Обучающие ноутбуки по Computer Vision

Привет! В этом репозитории вы найдёте материалы для изучения основ по компьютерному зрению.

В курсе используется Python 3.14

Для старта

- ставим uv
```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```
- тянем зависимости
```bash
uv sync --all-groups
```
После этого `uv` создаст `.venv` и поставит всё нужное для работы с курсом.
